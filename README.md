# Site da UMADMEGO

Este é o código-fonte do site da UMADMEGO (União de Mocidade das Assembleias de Deus Missão no Estado de Goiás).

## ✨ Tecnologias Utilizadas

*   **[Next.js](https://nextjs.org/)** - Framework React para produção.
*   **[React](https://reactjs.org/)** - Uma biblioteca JavaScript para construir interfaces de usuário.
*   **[TypeScript](https://www.typescriptlang.org/)** - Um superconjunto de JavaScript que adiciona tipagem estática.
*   **[Tailwind CSS](https://tailwindcss.com/)** - Um framework CSS utilitário para criar designs personalizados rapidamente.
*   **[Yarn](https://yarnpkg.com/)** - Gerenciador de pacotes.

## 🚀 Como Executar

Siga estas etapas para executar o projeto em sua máquina local.

### Pré-requisitos

*   [Node.js](https://nodejs.org/) (versão 16 ou superior)
*   [Yarn](https://yarnpkg.com/getting-started/install)

### Instalação e Execução

1.  **Clone o repositório:**

    ```bash
    git clone https://github.com/umadmego/umadmego-site-next.git
    ```

2.  **Acesse o diretório do projeto:**

    ```bash
    cd umadmego-site-next
    ```

3.  **Instale as dependências:**

    ```bash
    yarn install
    ```

4.  **Inicie o servidor de desenvolvimento:**

    ```bash
    yarn dev
    ```

5.  **Abra seu navegador e acesse:**

    [http://localhost:3000](http://localhost:3000)

## 部署

Este projeto é implantado no [Firebase Hosting](https://firebase.google.com/docs/hosting). Para fazer o deploy de uma nova versão, execute o seguinte comando:

```bash
yarn build && firebase deploy
```
